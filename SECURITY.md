# Reporting Security Issues

We take all security reports seriously and appreciate responsible disclosure.

Please do not create a public GitHub issue for a suspected vulnerability.
Instead, use GitHub Security Advisories to
[report a vulnerability privately](https://github.com/epam/ai-dial-react-file-manager/security/advisories/new).
Only the title and description are required to start a report.

The maintainers will acknowledge the report, investigate it, and keep the
reporter informed about remediation and disclosure timelines. We may request
additional information needed to reproduce or assess the issue.
